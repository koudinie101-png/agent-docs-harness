# ADR-0005: Отказ от встроенного локального web-визуализатора базы знаний

> **Статус:** Отклонено  
> **Дата:** 2026-10-01  
> **Теги:** #adr #architecture #rejected #visualization #cli  

---

> [!NOTE]
> **Отказное решение (`status: rejected`):** Данное решение фиксирует аргументированный отказ от внедрения встроенного HTTP-сервера и локального web-дашборда (`install.py --serve`) для предотвращения раздувания кодовой базы (Feature Creep) и нарушения принципа Zero Dependencies.

## 1. Контекст и проблема
На этапе формирования бэклога перспективных идей рассматривалась гипотеза создания автономного встроенного визуализатора базы знаний:
* Команда `python install.py --serve` поднимает локальный HTTP-сервер на Python stdlib (`http.server`).
* В браузере открывается интерактивная HTML/JS-страница с рендерингом графа связей заметок и интерактивной канбан-доски.
* Цель предложения: позволить разработчикам визуализировать связи базы знаний и канбан без необходимости устанавливать десктопное приложение Obsidian.

## 2. Решение
**Решение: ПОЛНОСТЬЮ ОТКЛОНИТЬ реализацию встроенного web-визуализатора.**

Архитектурный стандарт `agent-docs-harness` — это ультралегковесный, бескомпромиссно надежный CLI-инструмент и фреймворк дисциплин. Инструмент решает задачи развертывания, валидации и интеграции с AI-агентами. 

Для интерактивной визуализации графа связей и канбана признано безальтернативно лучшим решением использование **Obsidian** (бесплатного, гипербыстрого нативного приложения, для которого харнесс генерирует конфигурации `.obsidian/graph.json` и файлы разметки Kanban). Для работы без Obsidian основным интерфейсом служат дерево каталогов, Markdown-превью современных IDE (VS Code, Cursor, Windsurf) и индексная карта [[../00_Index|00_Index.md]].

## 3. Рассмотренные и отвергнутые варианты (Considered & Rejected Alternatives)

* **[Отклонено] Встроенный HTTP-сервер на `http.server` с бандлом D3.js / Cytoscape.js:**
  * *Причины отклонения:* 
    1. **Нарушение Zero Dependencies и раздувание бандла:** Для качественной отрисовки физического графа связей и интерактивного Drag-and-Drop канбана требуются тяжелые JS-библиотеки (D3-force, Cytoscape, Sortable). Их упаковка в base64 увеличила бы размер `install.py` с 75 КБ до 500+ КБ.
    2. **Уязвимости и платформенные проблемы:** Локальный веб-сервер создает риски блокировок сетевых портов, конфликтов с корпоративными файрволами, межсайтового скриптинга (CORS/CSRF) и зависших фоновых демонов при аварийном завершении консоли.
    3. **Низкое качество UI/UX по сравнению с нативным инструментом:** Любая доморощенная веб-версия графа на скорую руку будет на порядки уступать по плавности, фильтрации и удобству движку Obsidian Canvas и Graph View.
* **[Отклонено] Генерация статичной HTML-страницы со SVG-графом:**
  * *Причины отклонения:* Статический граф неинтерактивен, быстро теряет актуальность при добавлении заметок и не решает задачи полноценного управления канбан-доской.

## 4. Обоснование и последствия

### Плюсы отказа:
* **Сохранение чистоты и фокуса (Unix-философия):** Инструмент делает одну вещь идеально — развертывает Docs-as-Code каркас и дисциплины агентов.
* **Компактность дистрибутива:** Инсталлятор остается ультракомпактным скриптом (~75 КБ), скачиваемым через `curl` за доли секунды.
* **Отсутствие бремени поддержки:** Не требуется сопровождать веб-интерфейс, бороться с багами рендеринга в Safari/Chrome/Firefox и чинить мобильную верстку.

### Компромиссы:
* Пользователи, принципиально не использующие Obsidian, ориентируются по текстовым ссылкам, [00_Index.md](file:///c:/Users/Koudinie/Documents/antigravityProjects/agent-docs-harness/docs/00_Index.md) и встроенным средствам просмотра Markdown в IDE. Это признано полностью приемлемым компромиссом.
