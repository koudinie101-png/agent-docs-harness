## 3. Детали реализации

### 3.1. Структура `Zero_To_Hero_Guide.md`
1. **Введение: Что такое «Вайбкодинг со страховкой»?**
   * Развенчание мифа: почему классический бесконтрольный вайбкодинг неизбежно ломает проект через 500 строк кода.
   * Ментальная модель «Автопилот с датчиками»: агент пишет код, а харнесс Docs-as-Code не дает ему сойти с рельс.
2. **4 режима разработки через жизненные аналогии:**
   * *Режим 0 (Discovery):* «Тест-драйв идеи» — агент проверяет, взлетит ли идея, до того как писать код.
   * *Режим 1 (Planning):* «Чертеж дома» — согласовываем общий вид и функционал.
   * *Режим 2 (Specification):* «Список материалов и деталей» — конкретные файлы и проверки.
   * *Режим 3 (Implementation):* «Строительство» — агент пишет код и сам запускает тесты.
   * *Fast-Track:* «Быстрый ремонт» — экспресс-правка в 1 шаг для мелочей.
3. **Шпаргалка по AI-средам (Cheat Sheet):**
   * Где окно чата и правила в Antigravity, Cursor, Windsurf, Claude Code.
   * Как общаться с агентом: почему фраза *«сделай круто»* хуже, чем *«действуй по шагам через /kb-plan»*.
4. **Старт с чистого листа (Chat-First Bootstrapping):**
   * Как развернуть проект, отправив один готовый промпт в окно чата, без ручного ввода консольных команд.

### 3.2. Обновление `.agents/skills/kb-onboard/SKILL.md`
