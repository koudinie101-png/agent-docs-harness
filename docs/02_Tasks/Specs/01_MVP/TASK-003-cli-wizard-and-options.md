## 1. Цель задачи
Реализовать удобный интерактивный мастер в консоли (с подсказками, валидацией ввода и выбором вариантов) и полнофункциональный парсер аргументов командной строки (`argparse`) для работы в скриптах и CI.

---

## 2. Затрагиваемые файлы и компоненты
* `[MODIFY]` `install.py` — реализация CLI парсера и интерактивного диалога.

---

## 3. Детали технической реализации
1. **Интерактивный диалог:**
   - Определение поддержки интерактивного режима (`sys.stdin.isatty()`).
   - Если запущено без флагов в терминале:
     - Запрос имени проекта (дефолт: имя текущей папки).
     - Выбор технологического стека из нумерованного меню (1: Swift/iOS/macOS, 2: Web/TypeScript, 3: Python, 4: C#/.NET, 5: Generic).
     - Выбор целевого агента (1: Все [Рекомендуется], 2: Cline, 3: Claude Code, 4: GitHub Copilot, 5: Cursor, 6: Только AGENTS.md).
     - Выбор стратегии Git (1: Инициализировать локальный Git, 2: Помощь в подключении к GitHub, 3: Пропустить Git).
2. **Аргументы командной строки:**
   - `--name` / `-n`
   - `--stack` / `-s` (`swift`, `ts`, `python`, `dotnet`, `generic`)
   - `--agent` / `-a` (`all`, `cline`, `claude`, `copilot`, `cursor`, `generic`)
   - `--git` / `-g` (`local`, `github`, `none`)
   - `--non-interactive` / `-y` / `--yes`
   - `--target-dir` / `-d`

---

## 4. План верификации (Verification Plan)
- [ ] Запуск `python install.py -h` (отображает понятную справку с примерами).
- [ ] Запуск в неинтерактивном режиме с флагами `--non-interactive --name "TestApp" --stack swift`.
- [ ] Проверка отработки при отсутствии `stdin` (pipe из curl) с дефолтными значениями при `-y`.

- [ ] Ошибки ввода корректно обрабатываются с выводом понятных сообщений.
